# whisper (turu)

A deterministic knowledge-routing CLI for AI agents: canonical repo keys,
branch slugs, and scope-based knowledge storage/recall over `~/.whisper/`,
JSON envelope throughout, built on genesis-vibes conventions.

## Purpose

Agents accumulate operational knowledge across sessions, but "where does this
note go?" is a question models answer unreliably. turu turns that mechanical
routing layer into a binary: same inputs, same outputs, every machine.

## Commands

key, resolve, append, recall, distill, bundle, init, status, check,
consolidate, doctor, sync, feedback, skill install

## Install

### Binary (curl)

```bash
V=$(basename "$(curl -fsSLI -o /dev/null -w '%{url_effective}' \
  https://github.com/charly-vibes/whisper/releases/latest)" | sed 's/^v//')
TGT="$(uname -s | tr '[:upper:]' '[:lower:]')_$(uname -m | sed 's/^x86_64$/amd64/; s/^aarch64$/arm64/')"
curl -fsSL "https://github.com/charly-vibes/whisper/releases/download/v${V}/turu_${V}_${TGT}.tar.gz" | tar xz
chmod +x turu turututu whisper && sudo mv turu turututu whisper /usr/local/bin/
```

### Cargo

cargo install whisper-vibes
